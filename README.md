# WEATHER.EXE

A fictional forecast for Sundorp, built with the Next.js App Router and Tailwind CSS. The radar, alerts, and readings are jokes, not live weather data.

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The Chaos Console adjusts animation speed; the site honors your system's reduced-motion preference.

Forecast panels stack on small screens. Scroll within the hourly forecast to see all eight cards.

`npm run build` compiles, type-checks, and prerenders the production site.
